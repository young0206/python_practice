# Python Study

Python 기초 및 심화 강의를 수강하며 학습하고 실습한 내용을 기록한 저장소입니다.

강의 내용을 따라 예제 코드를 직접 작성하고 실행하며 Python을 학습했습니다.

## 📚 Study Contents

### 1. Python Basic

Python 기초 강의를 수강하며 진행한 실습입니다.

관련 실습 코드는 `basic/` 디렉토리에 정리되어 있습니다.

### 2. Python Advanced

Python 심화 강의를 수강하며 진행한 실습입니다.

관련 실습 코드는 저장소의 `chapterXX` 형식의 Python 파일에 정리되어 있습니다.
